# Code of Conduct

This project is a practical tool for people who want faster text input. Keep collaboration calm, specific, and respectful.

Expected behavior:

- Be kind and direct.
- Assume good intent, but respond to impact.
- Keep criticism focused on code, design, documentation, or behavior.
- Make issues reproducible when possible.
- Respect privacy and do not post secrets, API keys, recordings, or personal data.

Unacceptable behavior:

- Harassment or personal attacks.
- Publishing private information.
- Derailing issues with unrelated arguments.
- Repeated low-effort or hostile comments after maintainers ask you to stop.

Maintainers may moderate, edit, hide, or remove comments and issues that make the project harder to work on.
